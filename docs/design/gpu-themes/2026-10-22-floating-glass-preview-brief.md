# 浮动工具条式轻雾玻璃：首版样板

用户方向：浮动工具条式、通透、稍微一点雾感。当前先做可运行样板并提供实图，未批准替换生产主题。

## 视觉规格

- 单层外玻璃，内部通过标题、对齐和留白区分，保留 CPU/GPU/内存/磁盘/网络/流量统计。
- 玻璃面板为窄竖形；这次仅调整材质与前景细节，不做嵌套玻璃卡片。
- 背景由代码生成，使用浅色、有大轮廓的演示壁纸，不捕获用户桌面。
- 中央保留背景颜色与形状，只柔化细节；轻雾采用散射采样，不以强不透明白底代替。
- 边缘及圆角有连续曲率、折射、高光和厚度；避免整圈等宽强白描边。
- 外侧柔阴影形成悬浮感；背景、阴影和玻璃在同一 GPU 画面中合成。
- 文字与数值保持清晰，数值以中性色为主，告警与少量进度条使用强调色。

参考 token：前景墨色 `#18232D`、次级灰 `#52616D`、中性玻璃 `#F5F7FA`、蓝灰环境 `#B6C8DC`、少量青色 `#287E86`、温度强调 `#A16C32`。背景可含少量柔和紫色、蓝色与暖色大曲面。

字体角色：Segoe UI Variable 用于标题与正文，系统中文回退；数值保证稳定对齐，避免整面使用装饰字体。实际字形需检查裁切、对比与单位。

## 工程边界

- 样板执行模型：用户指定的 DeepSeek V4.1 Flash。
- 独占源码：`tools/GlassToolbarPreview/`。
- 实图输出：`docs/reviews/evidence/gpu-themes/2026-10-22-toolbar-preview/`。
- 不改生产主题、生产 shader、采样或用户设置。
- GPU backbuffer 导出 PNG；不是概念效果图，不宣称已集成到正式主面板。
- 运行只展示合成固定数据；不执行桌面捕获、WDA 排除或真实硬件采样。

## 首版查看重点

1. 能否明显看出背景透过材质，而不是不透明浅色面板。
2. 雾感是否仅柔化细节，没有模糊前景数字。
3. 玻璃边缘是否呈曲面厚度，而不是白色圆角边框。
4. 光影是否自然，文字是否足够清楚。
5. 源指标是否全部出现，中文/单位是否裁切。

这一轮不评价完整功能兼容或长时性能。用户看实图后再决定更清、更雾、边缘更薄或更厚。
