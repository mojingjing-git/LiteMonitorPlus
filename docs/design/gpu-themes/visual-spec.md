# Liquid Glass 与 Cyberpunk GPU 视觉规范

> 任务：R01  
> 状态：样板实现输入，等待 G2 用户分别确认  
> 执行模型：DeepSeek V4.1 Flash

## 1. 设计与素材边界

两套主题共用场景、几何、文字和资源合同，但材质、色板、层级与动效分别实现。参考苹果和微软公开设计/API 文档只用于方向，不复制品牌控件、图标或截图。原型背景、纹理和状态图由程序生成或使用原创图形。

不采用的默认表现：

- 所有线条同时发光或所有文字加辉光。
- 大量色散、彩虹边、水波和持续抖动。
- 大面积扫描线、网格、噪点叠满整个面板。
- 用一张静态效果图冒充实时 GPU 结果。
- 用缩小字号把 4 卡内容塞进窄面板。

## 2. Liquid Glass

### 2.1 视觉意图

面板像一块有厚度和边缘曲率的透明玻璃。背景保持可辨认，中心只做轻度散射；靠近轮廓的位置产生连续透镜位移和强度不同的边缘高光。文字和告警完全位于折射材质之外，不闪烁、不重影。

### 2.2 色板

| Token | 值 | 用途 |
|---|---|---|
| `glass.surface` | `#B8D9F5 @ 8%` | 极轻冷色表面 |
| `glass.edgeCool` | `#D8F2FF` | 左上冷高光 |
| `glass.edgeWarm` | `#FFF2D9` | 右下暖反射 |
| `glass.shadow` | `#07111C @ 38%` | 外轮廓阴影 |
| `glass.text` | `#F7FBFF` | 主文字 |
| `glass.textMuted` | `#B9C8D7` | 单位、次级文字 |
| `glass.normal` | `#58E5C2` | 正常值 |
| `glass.warning` | `#FFC857` | 警告 |
| `glass.danger` | `#FF6B73` | 危险 |

### 2.3 几何与材质参数

| 参数 | 首版值 |
|---|---|
| 圆角半径 | 24 logical px |
| 轮廓宽度 | 1.25 logical px |
| 折射位移 | 边缘最大 2.5 logical px，中心为 0 |
| 背景清晰采样 | 中心保留 65% 以上 |
| 模糊核 | 边缘来源可做 9 tap 小核散射；不接受全图重糊 |
| 高光 | 左上窄弧和右下宽弱弧，强度分别 0.8/0.25 |
| 阴影 | 向下 8 px、扩散 18 px、随形状而不是矩形盒 |
| 表面 tint | 冷色 8%，随背景亮度平滑调整 |

### 2.4 布局

- 标题行保持单一基线；CPU/GPU 主数值尺度最高。
- 分组标题与数值至少保留 8 logical px 间隔。
- 圆角片、完整监控分组、真实数值面板三块内容必须同屏出现。
- 窄面板先隐藏低优先级单位或折行，不整体缩小字体。

### 2.5 动效

- 边缘折射随窗口位置和背景采样变化，材质本身无需循环闪烁。
- 状态变化高光在 180 ms 内进入稳定值。
- 拖动期间保持同一材质代次，只更新裁切和位置。
- 暂停所有材质动效后，静态画面仍能辨认玻璃、文字和告警。

## 3. Cyberpunk

### 3.1 视觉意图

深色工业仪表面板，主框体、连接件、分组槽和数据区形成明确结构。冷青主灯承担信息层级，琥珀用于焦点/警告，红色仅用于危险。霓虹是局部材质层，正文使用干净前景。

### 3.2 色板

| Token | 值 | 用途 |
|---|---|---|
| `cyber.base` | `#0A1017` | 工业底板 |
| `cyber.panel` | `#121B24` | 次级槽体 |
| `cyber.line` | `#345064` | 非发光结构线 |
| `cyber.cyan` | `#48E6F2` | 冷色主灯、正常状态 |
| `cyber.amber` | `#FFB84D` | 焦点、警告 |
| `cyber.red` | `#FF4967` | 危险 |
| `cyber.text` | `#E8F7FA` | 主文字 |
| `cyber.textMuted` | `#91A7B2` | 单位、辅助文字 |

### 3.3 几何与材质参数

| 参数 | 首版值 |
|---|---|
| 主框切角 | 14 logical px |
| 次级切角 | 8 logical px |
| 结构线 | 1 logical px，非发光 |
| 亮核 | 1.5 logical px，局部 |
| 近光晕 | 6 logical px，随亮核局部扩散 |
| 环境反射 | 最大 12% 强度 |
| 底板 | 92% 不透明，弱纵向金属纹理 |
| 分级 | 标题/主值/单位/辅助信息四级 |

### 3.4 布局

- 样板至少含 CPU、GPU、双列 NET/DISK、进度条、正常/警告状态。
- 1 卡与 4 卡共享同一视觉规则，4 卡不压缩文字到不可读。
- 窄面板删减低优先级单位和装饰，不用统一缩放塞入。
- 关闭动效后保留完整框体、分级和状态区分。

### 3.5 动效

- 扫光只沿局部进度条或状态槽运动，周期 2.8 秒，禁止全屏扫光。
- 数值变化使用一次 140 ms 亮度反馈；文字位置不变。
- 告警使用有限频率脉冲，但静帧仍可辨识。
- 不使用持续文本抖动、随机故障剪切或无意义闪烁。

## 5. 固定场景

首版固定输入包含：

- 深色渐变、浅色渐变、彩色块、细字和棋盘格五类背景区域。
- CPU 62%、GPU 78%、NET 24.8 MB/s、DISK 41%。
- 正常、警告、危险三种值及缺失传感器状态。
- 1 GPU 与 4 GPU 两种场景。
- 1280x800、720x800、1280x420 三种窗口形态。
- 时间和随机种子固定，重复渲染哈希必须可比较。

机器可读 token 见 `docs/design/gpu-themes/tokens.json`。
