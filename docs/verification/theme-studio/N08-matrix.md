## 1. 交互与功能验证项细则

### 1.1 工作区明暗跟随与视觉规范

- **明暗策略接线**：工作室内部工作区配色严格跟随生产策略（`ThemeStudioForm` 灰白浅色工作区，检查器白底与弱灰边框），非客户区保持 Windows 11 原生 DWM 标题栏与窗口阴影，不重做非客户区。
- **色板样本隔离**：主题配色样本（颜色条、指示器、色卡）始终如实反映主题草稿值，不被工作区自身的主题换色所覆盖。
- **状态栏与路线标注**：状态栏明确展示“预览路线：经典渲染（同源）/ GPU 场景（同源）/ 兼容外观 · 常规绘制”，彻底清理所有历史临时占位文案。

### 1.2 布局自适应与分栏偏好

- **紧凑布局阈值**：三栏式工作区支持自适应收缩，当主窗口宽度收紧至紧凑阈值（< 900px）时，资料库与检查器支持折叠/最小可见宽度，所有核心控件（保存、另存为、撤销/重做、应用、导出下拉）保持完全可达。
- **无操作裁切**：在 100% DPI 标准分辨率下，检查器底部保留占位安全边距，滚动到底部时最后一行（包括“恢复默认”链接与共享标注）完全显示无裁切。

### 1.3 辅助功能与键盘可达性

- **键盘快捷键**：
  - `Ctrl+S`：保存当前会话（草稿写入文件，更新已保存状态与基线摘要）；
  - `Ctrl+Shift+S`：另存为新主题文件（弹出校验合法的名称对话框）；
  - `Ctrl+Z`：撤销上一笔字段编辑；
  - `Ctrl+Y` / `Ctrl+Shift+Z`：重做已撤销的字段编辑。
- **Tab 焦点与导航**：检查器内所有属性编辑控件（颜色框、数值框、复选框、下拉框、恢复默认链接）具备线性 Tab 遍历顺序与可见焦点框。
- **屏幕阅读器**：关键操作按钮与下拉项已配置明确的 `Text` / `AccessibleName`，状态栏状态变化具备文本通知。

## 3. 验收结论与硬指标符合性

1. **已验证部分 (PASS)**：
   - 100% DPI 主屏横屏与 100% DPI 负坐标副屏竖屏完全覆盖；
   - 125%~200% 常用缩放梯级代码逻辑与界面缩放函数验证通过；
   - 键盘快捷键（Ctrl+S / Ctrl+Shift+S / Ctrl+Z / Ctrl+Y）与 Tab 导航完备；
   - 紧凑布局与无裁切滚动正常。
2. **客观受限未验证项 (NOT-VERIFIED)**：
   - 物理 250%~300% 缩放、物理 4K 面板横向大场景、混合 DPI 跨屏拖拽、硬件物理拔屏重开共 4 项受限于当前执行机硬件条件，依据计划 §4 与 §12 规则**如实登记为 NOT-VERIFIED，严禁用虚拟显示冒充通过**。
3. **门禁放行判定**：
   - 本机可验证的核心体验项全部 PASS，未覆盖项边界已隔离并载入后续硬件测试机备忘，放行进入 N09 / N10 交付收口。
