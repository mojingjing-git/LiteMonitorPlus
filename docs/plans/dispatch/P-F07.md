## 要点（完整步骤见拆解计划 §4 P-F07）

1. 设备目录：`StableId / RuntimeId / DisplayName / ParentId / Kind / IsPresent`；GPU/磁盘/风扇共用身份原则，不强行共用硬件 API。
2. 展示槽位 vs 设备身份分离；保留 `GPU.{index}.*` 公开指标 Key，用持久化槽位绑定稳定设备 ID；不把裸 PCI 路径拼进 Key。
3. 验证 LHM Identifier 跨枚举/重启稳定性；优先 PnP 实例/设备唯一标识与总线信息；LUID/枚举序号/显示名不可单独作跨重启身份；不可靠时显式标记不稳定，不猜绑定。
4. 磁盘选择项 Label+Value；同名型号加可区分后缀；Windows 计数器实例单独映射；**枚举不得为取 ID 先做 SMART 探测**（不得绕过 F08 策略）。
5. 旧配置仅唯一匹配迁移；歧义保留旧值+提示，不随机选第一块；GPU 槽位按可证明映射迁移；迁移幂等/原子/备份。
6. 手动首选卡消失保持绑定显示离线；自动模式可重选但公开选择；`MonitoredGpuCount=1` 语义不变（不为修 #450 静默改全卡）。
