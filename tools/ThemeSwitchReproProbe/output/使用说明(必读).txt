=========================================================
         					LiteMonitor++ 使用说明
					     [ 开源 | 免费 | 安全 | 透明 ]
=========================================================

[1] 运行环境 (必读)
----------------------------------------------------------------
本软件基于微软最新的 .NET 8 框架开发。
如果双击软件无反应或报错，请确保安装了【.NET Desktop Runtime 8.0】环境。

* 下载地址 (微软官网):
  https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/runtime-desktop-8.0.22-windows-x64-installer


[2] 权限与驱动说明
----------------------------------------------------------------

1. 管理员运行：
   请始终以【管理员身份】运行本程序。

2. 为了能够读取CPU温度/频率/功耗等数据，本软件需依赖PawnIO驱动
   * 软件启动时会自动检测是否安装PawnIO驱动，若未安装会自动提醒安装。
   * 如果自动安装失败，您可以手动下载 PawnIO 驱动进行安装。
   * 下载地址: https://raw.githubusercontent.com/mojingjing-git/LiteMonitorPlus/master/resources/assets/PawnIO_setup.exe
   * 驱动包与 FPS 组件在下载后都会做 SHA256 完整性校验，校验不通过会中止安装，
     不会执行校验失败的下载文件。


[3] 关键文件与数据管理
----------------------------------------------------------------
为了方便备份或重置，以下是核心文件的用途：

* Settings.json (配置文件)
  保存了显示模式、监控项目、告警阈值等所有设置。
  > 故障解决：如果软件配置错乱无法启动，删除此文件可重置为默认状态。

* TrafficHistory.json (流量记录)
  记录了每日的上传/下载流量统计数据。
  > 隐私清理：如需重置历史流量统计，可直接删除此文件，软件会自动重建。

* LiteMonitor++_Error.log（崩溃错误日志）
  软件运行崩溃或异常时的日志记录。

* resources/themes/*.json (主题文件)
  您可以直接编辑文本修改配色，或使用软件内置的【主题编辑器】进行可视化修改。

* resources/lang/*.json (语言包)
  支持多语言（中/英/日/韩等）。如需修正翻译或修改内容，可直接用记事本编辑对应文件。

* resources/plugins/*.json (插件文件)
  存放插件配置与扩展功能定义，可自由增删插件实现个性化监控。
  > 自定义插件：将符合规范的插件 JSON 放入此目录，重启软件即可生效；删除对应文件即可卸载插件。

[4] 插件市场
----------------------------------------------------------------
设置 -> 插件市场，可以直接从社区插件仓库一键安装插件。

* 插件源（固定，程序内不提供修改入口）:
  https://github.com/mojingjing-git/awesome-litemonitor-plugins
  索引文件:
  https://raw.githubusercontent.com/mojingjing-git/awesome-litemonitor-plugins/main/index.json

* 市场插件存放位置:
  与内置插件同一个目录 —— 程序目录下的 resources/plugins/。
  文件名规则为 "<插件 id>.json"，例如 public_ip_info.json。
  （内置插件与市场插件同目录，因此整个程序目录连同已装插件可以整体拷贝迁移。）

* 安装与卸载:
  在市场页点击【安装】/【卸载】即可。只有通过市场安装的插件才能被市场卸载，
  内置插件永不会被卸载。安装时会校验下载内容的 SHA-256，校验不通过会中止安装。
  升级插件后，市场页会显示【可更新】。

* 权限提示:
  市场插件装在程序目录。若程序位于 C:\Program Files\ 等受保护位置，
  安装会因权限不足失败，请以【管理员身份】运行本程序。

* 插件安全:
  插件是纯声明式 JSON 配置，不具备执行第三方脚本或代码的能力；
  但插件会按其配置发起网络请求，可能把您填写的 API Key 发送给它声明的接口。
  安装前请查看该插件 README 里列出的请求域名。
  带【未经验证】标记的插件表示尚未经过审核 Agent 实机验证，请自行判断是否信任。


[5] 关于本项目 (Open Source)
----------------------------------------------------------------
LiteMonitor++ 是一款基于开源项目 LiteMonitor（原作者 Diorser，MIT 协议）
派生修改的免费软件，源码完全公开。

安全说明：
  * 程序本体不包含任何后门或隐私窃取逻辑。
  * 本程序的【插件系统】只加载【纯声明式 JSON 配置】（去哪取数、怎么提取、怎么显示），
    不会下载或执行任何第三方脚本与可执行代码。但插件会按其配置发起网络请求，
    可能把你填写的 API Key 发送给它声明的接口 —— 请只安装可信来源的插件，
    并留意插件 README 里说明的请求域名。
  * 因涉及底层硬件数据读取，部分杀毒软件可能会拦截此程序。
    如果运行或设置开机启动时出现拦截，请将程序目录添加至杀软信任/白名单。

  支持同时监控多张显卡，温度/占用/功耗/显存等指标按卡分别显示。
  详见设置 -> 系统与硬件 -> 监控显卡数量。

    设置的数量超过实际可用张数时会自动夹紧到实际张数。
